## The short version

Sigil is built by Tophhie Cloud for organisations on Microsoft 365. An
administrator designs one or more signature templates in the web portal. An
Outlook add-in, deployed centrally, fires whenever someone starts a message,
asks the Sigil API for that person's signature, and applies it. The API
personalises the template from Microsoft Graph, so every signature carries the
right name, title, phone number and address without anyone typing them.

Changes to a template, an image, a banner or a footer reach users within seconds.
Nothing is redeployed and nobody is asked to do anything.

Pricing is £0.70 per licensed mailbox per month with a 14 day free trial. Shared
and resource mailboxes are free. Every feature is included at that price.
